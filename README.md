# FIAP DevOps - Anotações

Este repositório reúne minhas anotações da pós-graduação em DevOps.

A ideia não é transcrever tudo da aula, mas registrar os conceitos principais com uma explicação simples, para facilitar a revisão depois.

## Módulos

1. [CI/CD](./01-ci-cd)

## Como as anotações estão organizadas

Cada módulo tem uma pasta própria. Dentro dela, cada aula ou submódulo fica em uma pasta numerada com um `README.md`.

Exemplo:

```text
01-ci-cd/
  01-fundamentos-e-arquitetura-de-pipelines-ci-cd/
    README.md
  02-otimizacao-e-escalabilidade-de-pipelines/
    README.md
  03-entrega-continua-com-kubernetes/
    README.md
```

## Por que usar README.md?

O `README.md` é uma boa escolha porque:

- aparece automaticamente quando abrimos a pasta no GitHub;
- funciona bem para texto, listas, links e exemplos de código;
- deixa cada aula fácil de consultar;
- evita criar vários arquivos soltos sem contexto.
