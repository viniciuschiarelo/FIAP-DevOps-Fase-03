## Ideia principal do módulo

CI/CD existe para diminuir o tempo entre escrever uma alteração no código e entregar essa alteração funcionando com segurança.

Em vez de depender de várias etapas manuais, a equipe automatiza build, testes, validações, publicação de imagem e deploy. Isso reduz erro humano, acelera entrega e aumenta a confiança no processo.
